# Guía de soporte para operación de campo

## Antes de salir

- Iniciar sesión con internet y confirmar entidad, usuario, fecha/hora y formularios asignados.
- Abrir cada formulario para verificar que la versión y las capas territoriales estén precargadas.
- Confirmar permisos de cámara y ubicación, batería, almacenamiento y cargador portátil.
- Pulsar “Sincronizar” y salir solo cuando no existan pendientes inesperados.

## Trabajo sin señal

- Mantener la aplicación instalada; no borrar datos, caché ni almacenamiento de Control G.
- Finalizar cada registro y comprobar que aparezca como pendiente de sincronización.
- Si la aplicación se cierra, abrirla de nuevo: el borrador debe continuar disponible.
- No compartir el dispositivo ni enviar fotos de formularios por aplicaciones personales.

## Al recuperar internet

1. Abrir Control G y esperar una conexión estable.
2. Pulsar “Sincronizar ahora”. Los medios se envían antes que la respuesta.
3. Mantener la aplicación abierta hasta que el contador llegue a cero.
4. Confirmar con coordinación que la respuesta aparece en la bandeja y que sus evidencias abren.

## Si una sincronización falla

- No repetir el formulario y no desinstalar la APK.
- Registrar hora, formulario, texto exacto del error y estado de red; no capturar respuestas sensibles.
- Probar otra red y reintentar una vez.
- Escalar con el identificador operativo mostrado, modelo Android y versión de Control G.
- Soporte debe revisar asignación, RLS, Storage, cola y logs antes de manipular el dispositivo.
